# Тест по психологии

Веб-приложение для подготовки к вступительным испытаниям по психологии. Реализовано на React + Vite с анимациями Framer Motion.

## Возможности

- стартовый экран с кнопкой «Начать тест»;
- 20 вопросов с одним правильным ответом;
- таймер на 20 минут и автоматическое завершение при истечении времени;
- индикатор прогресса «Вопрос N из 20»;
- звуки правильного и неправильного ответа;
- результат после прохождения: правильные ответы, ошибки, процент успешности и итоговая оценка;
- список ошибок с правильными ответами;
- кнопка «Пройти заново»;
- сохранение лучшего результата в `localStorage`;
- светлая и тёмная тема;
- адаптивный современный интерфейс;
- готовность к деплою на Vercel.

## Оценивание

- 90–100% — Отлично;
- 75–89% — Хорошо;
- 50–74% — Удовлетворительно;
- менее 50% — Неудовлетворительно.

## Запуск локально

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite выведет в терминал, обычно `http://localhost:5173`.

## Сборка для production

```bash
npm run build
```

Проверить production-сборку локально:

```bash
npm run preview
```

## Деплой на Vercel

1. Загрузите проект в GitHub/GitLab/Bitbucket.
2. Импортируйте репозиторий в Vercel.
3. Vercel автоматически определит Vite-проект.
4. Убедитесь, что команда сборки — `npm run build`, а директория результата — `dist`.
5. Нажмите **Deploy**.
